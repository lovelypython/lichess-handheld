# 3D enclosure

Files in this directory:

- `lichess_handheld_enclosure_v05.scad`: parametric source.
- `lichess_handheld_enclosure_v05.zip`: v05 printable package containing the front shell, rear shell, battery cover, ESP clip, and fit-test model.
- `lichess_handheld_enclosure_v06_back.zip`: v06 rear-shell update with the lowered ESP area.
- `GPT6_ESP32C5_Lichess_Enclosure_Handoff.md`: dimensions, fit notes, hardware assumptions, and print guidance.

The v05 design targets the 4-inch 480x320 display, ESP32-C5 board, 18650 battery compartment, rocker switch, antenna clearance, short M2.5 case screws, and Bambu Lab A1 mini FDM printing. STL files remain packaged so the enclosure can be downloaded as one reproducible artifact.
