# Recovered development history

This repository was reconstructed from the original source exports, in their
chronological order. The Git log is the authoritative timeline.

Stages preserved:

1. Mac Python simulator: initial build through v5.5.
2. ESP32-C5 PlatformIO port: v0.1, v0.2, v0.3, and v1.0.
3. Firmware v1.0.2 through v1.0.7.
4. Independent XPT2046 touch diagnostics (baseline, standalone, software-SPI).
5. Firmware v1.0.8 through v1.0.13: regional refresh, verified TLS, landscape,
   touch calibration, board refresh, and puzzle feedback.

`v1.0.1` is a metadata-only checkpoint because its original source export is
not available. Every other listed checkpoint comes from a recovered source ZIP.

## Credentials

No access token is tracked. Firmware snapshots use
`REPLACE_WITH_YOUR_LICHESS_TOKEN` as a placeholder; provide a fresh token only
in a local, ignored secrets file before building.
